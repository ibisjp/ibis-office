# GJフォント
## 本フォントの特徴
GJフォントは、行政事務標準文字として整備された文字集合のグリフを収録したフォントです。
行政事務標準文字とは、行政手続きにおける文字の統一的な取り扱いを目的として整備された文字集合であり、MJ文字図形名に対応するMJ文字集合を拡張する形で追加された文字を含んでいます。
収録されている文字の対応については、同梱のcharacters-map.pdfをご参照ください。
 
## 収録物について
- acgjm.ttf --- TrueTypeフォント形式
- acgjm.woff2 -- Webフォント形式
- characters-map.pdf-- 文字対応表
- OFL.txt-- SIL Open Font License 1.1
- Readme.md -- 本ファイル
